Manage your tickets and make the storefront your own. Publishing requires access to your GitHub repository.

Use a short-lived token restricted to this repository, with Contents: read and write. The token stays in memory, goes only to GitHub and is cleared on logout, refresh or after 15 minutes of inactivity. Never share it in a chat.

First time? Set up your admin access +
  1. Open GitHub’s fine-grained token settings ↗.
  2. Choose the account that owns your site. Set a short expiry.
  3. Select Only select repositories, then VoucherLobang.
  4. Under Repository permissions, set Contents to Read and write. Leave other permissions unchanged.
  5. Generate the token, paste it above and connect. Revoke it in GitHub when no longer needed.
